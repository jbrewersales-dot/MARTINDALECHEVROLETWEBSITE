How this works

  • Identical means the same year, make, model, trim and drive (4WD, AWD and so on). Used cars also have to be within 15,000 miles of ours.
  • Prices and listings come from dealer websites across the country, collected by MarketCheck. A listing can be sold or repriced before this page updates, so call before you go.
  • Auction cars (Manheim, ADESA, ACV) aren't included. Those sites need a dealer login.
  • The list updates by itself once a week, on Monday morning.
